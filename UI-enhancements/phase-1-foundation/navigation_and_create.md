# Navigation and Global Create — Phase 1

## Scope

Hash-based single-page navigation with an active state and no dead links. The global Create button exposes only actions valid for the current context.

## Actions

- Product space, project, feature, story, sprint, release, test case, defect, dependency.
- Project-dependent actions require a selected project.

## Acceptance

- Browser back/forward and direct hashes work.
- Every visible action has a handler or is visibly marked unavailable.
- Selected product space/project remain synchronized with the displayed data.
