# Releases — Phase 3

## Scope

Release CRUD, feature/story assignment, and calculated readiness.

## Readiness

Derived from completed/blocked stories, critical defects, test execution, and feature completion—never hard-coded.

## Actions

Create/edit/mark ready/close/archive; add/remove work items; generate report.

## Acceptance

- Release membership is project-local and metrics update after related mutations.
