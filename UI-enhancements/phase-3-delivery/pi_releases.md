# PI Releases — Phase 3

ReleaseLens uses four three-calendar-month Program Increments per year. The mandatory hierarchy is Product Space → Project → PI Release → Feature → User Story.

Implemented foundation: structured year/PI number, exact calendar dates, project/year/PI uniqueness, project-scoped year generation, mandatory feature/story PI foreign keys, story inheritance, grouped UI dropdowns, and cross-project validation.

Remaining UI: dedicated PI management screen for create/rename/edit/archive/restore/move-work/delete, yearly roadmap columns, PI readiness, and browser automation coverage.
