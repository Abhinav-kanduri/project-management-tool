# Backlog — Phase 2

## Scope

Project → Feature → User Story hierarchy from PostgreSQL.

## Capabilities

- Create/edit/archive/restore, search, status/priority/points filters.
- Inline edits, bulk status/sprint/release assignment, CSV export.
- Persisted rank ordering with optimistic updates and rollback.

## Acceptance

- Mutations refresh Overview, Features, Stories, Board, and metrics.
- Moving or filtering cannot expose another project's items.
