# User Stories — Phase 2

## Scope

Complete story CRUD and acceptance-criteria editing.

## Fields

Persona, goal, benefit, description, feature, sprint, release, status, priority, points, assignee, rank, and labels.

## Actions

Create/edit/duplicate/archive/restore, move feature/project, assign sprint/release, generate criteria/tests.

## Acceptance

- Criteria add/edit/reorder/complete/delete persist separately.
- Story parent, sprint, and release must belong to the same project.
